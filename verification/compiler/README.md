# Compiler Verification

This area is for MPLC behavior rather than MPL language syntax.

Examples include:

- Compiler exit status
- Error reporting
- Line and column reporting
- Multiple-error summaries
- Standard output versus standard error
- Include-file resolution
- Command-line options
- Output-file replacement
- Behavior of an existing `.mpx` after a failed compile

Add a focused verification topic only when it is ready to be tested.
