# Language Verification

This area verifies MPL syntax and language features.

A language case answers questions such as:

- Does this syntax compile?
- Is this construct accepted by the target MPLC build?
- What exact spelling or structure does the compiler require?

Runtime behavior should be recorded separately when compilation alone does not answer the question.

## Initial Sequence

The first verification topic is:

```text
program-structure/
```

Future topics can be added only when they are ready to be tested, for example:

```text
constants/
data-types/
operators/
strings/
arrays/
records/
includes/
```

Do not create empty topic directories merely to reserve names.
