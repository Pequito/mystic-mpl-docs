# Contributing

Contributions are welcome.

This project is focused on improving documentation and examples for Mystic Programming Language.

## Contribution Types

Useful contributions include:

- MPL syntax notes
- Working MPL examples
- Corrections to existing documentation
- Clarification of confusing behavior
- Mystic BBS integration examples
- ANSI/screen output examples
- Menu system examples
- File I/O examples
- User data examples

## Style Guidelines

Please keep documentation clear, practical, and example-driven.

Prefer this style:

```text
Explain the purpose.
Show a small example.
Explain what the example does.
Mention any known limitations or version-specific behavior.
